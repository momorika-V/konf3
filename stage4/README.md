# Ассемблер и интерпретатор УВМ -- Этап 4. АЛУ: циклический сдвиг

## 1. Общее описание

Учебная виртуальная машина (УВМ), вариант 22. Этап 4 завершает
интерпретатор: добавлено выполнение арифметико-логической команды
-- побитовый циклический сдвиг влево (`rol`).

Ячейка памяти имеет ширину 21 бит (как поле константы в `load`),
поэтому сдвиг выполняется по модулю 21, а бит, вышедший за старший
край, возвращается в младший. Величина сдвига берется из памяти
и приводится по модулю ширины ячейки.

Язык реализации: Python 3, для разбора YAML -- PyYAML.
Весь код этапов 1--4 -- в одном файле `src/main.py`.

## 2. Спецификация УВМ (вариант 22)

Команда -- 10 байт, биты нумеруются от младшего к старшему.

| Команда | Код (A) | Поля (биты) | Смысл |
|---|---|---|---|
| Загрузка константы | 17 | B: 6--29, C: 30--50 | память[B] = C |
| Чтение из памяти | 43 | B: 6--29, C: 30--53 | память[B] = память[C] |
| Запись в память | 21 | B: 6--29, C: 30--38, D: 39--62 | память[память[D] + C] = память[B] |
| Циклический сдвиг влево | 57 | B: 6--29, C: 30--53, D: 54--77 | память[C] = память[D] цикл.сдвиг влево на память[B] |

## 3. Язык ассемблера (формат YAML)

## 4. Параметры запуска

Режим выбирается по расширению входного файла:

```
python src/main.py <вход.yaml> <выход.bin> [--test]        ассемблер
python src/main.py <вход.bin> <дамп.csv> [начало конец] [--test]
```

- `--test` у ассемблера печатает машинный код, у интерпретатора --
  трассировку выполняемых команд (`адрес: команда и поля`).

## 5. Обработка ошибок

Все ошибки этапов 1--3 (файлы, YAML, поля команд, размер бинарника,
диапазон дампа). Код возврата: 0 -- успех, 1 -- ошибка.

## 7. Запуск и тесты

Требуется Python 3.8 или новее. Зависимость устанавливается
автоматически при первом запуске скрипта (либо вручную:
`python -m pip install PyYAML`).

| Действие | Windows | Linux |
|---|---|---|
| Диалоговый запуск | `run.bat` | `sh run.sh` |
| Тесты | `run.bat test` | `sh run.sh test` |
| Демонстрация rol | `run.bat demo` | `sh run.sh demo` |
| Ассемблер напрямую | `python src\main.py examples\rol_demo.yaml out.bin` | `python3 src/main.py examples/rol_demo.yaml out.bin` |
| Интерпретатор напрямую | `python src\main.py out.bin dump.csv 195 215` | `python3 src/main.py out.bin dump.csv 195 215` |

Ожидаемый вывод `run.bat demo` (дамп адресов 195..214, где лежат
результаты):

```
200,1
201,1
202,65535
203,2
204,1048576
210,2        <- rol(1, 1)
211,262140   <- rol(65535, 2)
212,1        <- rol(1048576, 1): старший бит ушел в младший
```

## 8. Тестирование

Тесты этапов 1--3 плюс: сдвиг малого значения, нулевой сдвиг,
полный оборот (сдвиг на ширину ячейки не меняет значение),
переход старшего бита в младший, сдвиг на величину больше ширины
ячейки, команда `rol` в памяти и тестовая программа
`examples/rol_demo.yaml`.
