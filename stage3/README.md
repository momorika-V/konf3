# Ассемблер и интерпретатор УВМ -- Этап 3. Память и базовые команды

## 1. Общее описание

Учебная виртуальная машина (УВМ), вариант 22. Этап 3 добавляет к
ассемблеру (этапы 1--2) интерпретатор: модель объединенной памяти
(команды и данные в одном адресном пространстве), цикл
интерпретации (чтение команды -- перевод в промежуточное
представление -- выполнение) и команды загрузки константы, чтения
и записи в память. Результат работы сохраняется в CSV-дамп памяти.

Язык реализации: Python 3, для разбора YAML -- PyYAML.
Весь код этапов 1--3 -- в одном файле `src/main.py`.

## 2. Спецификация УВМ (вариант 22)

Команда -- 10 байт, биты нумеруются от младшего к старшему.

| Команда | Код (A) | Поля (биты) | Смысл |
|---|---|---|---|
| Загрузка константы | 17 | B: 6--29, C: 30--50 | память[B] = C |
| Чтение из памяти | 43 | B: 6--29, C: 30--53 | память[B] = память[C] |
| Запись в память | 21 | B: 6--29, C: 30--38, D: 39--62 | память[память[D] + C] = память[B] |
| Циклический сдвиг влево | 57 | B: 6--29, C: 30--53, D: 54--77 | память[C] = память[D] цикл.сдвиг влево на память[B] |

Команда сдвига (`rol`) ассемблируется, но выполняется начиная
с этапа 4.

## 3. Язык ассемблера (формат YAML)

Не изменился с этапа 1 (полное описание -- в `stage1/README.md`):

```yaml
- load:
    addr: 67       # память[67] = 619
    value: 619
- read:
    dst: 737       # память[737] = память[274]
    src: 274
- write:
    src: 662       # значение берется из память[662]
    offset: 337    # смещение: 0..511
    base: 305      # в ячейке 305 лежит адрес-указатель
- rol:
    dst: 189       # результат в память[189]
    value: 940     # что сдвигаем: память[940]
    count: 766     # на сколько: память[766]
```

## 4. Модель памяти и дамп

- Память -- единое адресное пространство: программа загружается
  с адреса 0 (каждая команда -- 10 байт), данные -- выше.
- Адрес складывается по модулю 2^24 (ширина адресного поля).
- Незаписанные ячейки при чтении равны 0.
- Дамп памяти -- CSV-файл с колонками `address,value`, значения
  десятичные. По умолчанию дампятся адреса 0..255, диапазон
  задается двумя необязательными аргументами.

## 5. Параметры запуска

Режим выбирается по расширению входного файла:

```
python src/main.py <вход.yaml> <выход.bin> [--test]        ассемблер
python src/main.py <вход.bin> <дамп.csv> [начало конец] [--test]
```

- `--test` у ассемблера печатает машинный код, у интерпретатора --
  трассировку выполняемых команд (`адрес: команда и поля`).

## 6. Обработка ошибок

Все ошибки этапов 1--2 плюс:

- файл программы не найден или не читается;
- размер бинарного файла не кратен 10 байтам;
- неизвестный код команды при декодировании;
- адреса дампа нечисловые, отрицательные или начало больше конца;
- входной файл без расширения `.yaml`/`.yml`/`.bin` -- сообщение
  с подсказкой, как определить режим.

## 8. Запуск и тесты

Требуется Python 3.8 или новее. Зависимость устанавливается
автоматически при первом запуске скрипта (либо вручную:
`python -m pip install PyYAML`).

| Действие | Windows | Linux |
|---|---|---|
| Диалоговый запуск | `run.bat` | `sh run.sh` |
| Тесты | `run.bat test` | `sh run.sh test` |
| Копирование массива | `run.bat demo` | `sh run.sh demo` |
| Ассемблер напрямую | `python src\main.py examples\copy.yaml out.bin` | `python3 src/main.py examples/copy.yaml out.bin` |
| Интерпретатор напрямую | `python src\main.py out.bin dump.csv 0 120` | `python3 src/main.py out.bin dump.csv 0 120` |

Ожидаемый вывод `run.bat demo`:

```
Команд: 10. Размер файла: 100 байт. Записан: temp\copy.bin
Выполнено. Дамп памяти (адреса 0..255) записан: temp\dump.csv
```

В `temp/dump.csv`: адреса 0..99 -- байты машинного кода (память
единая), 100..104 -- исходный массив 11, 22, 33, 44, 55,
110..114 -- копия.

## 9. Тестирование

Тесты этапов 1--2 плюс: декодирование слов спецификации, неизвестный
код команды, каждая из команд load/read/write (включая запись по
указателю со смещением), тестовая программа копирования массива,
ошибки размера файла и диапазона, проверка CSV-дампа.

```

$ sh run.sh test
...
Ran 55 tests in 0.031s

OK
```
