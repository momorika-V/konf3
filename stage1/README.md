# Ассемблер УВМ -- Этап 1. Промежуточное представление

## 1. Общее описание

Учебная виртуальная машина (УВМ), вариант 22. Этап 1: CLI-приложение,
которое читает программу на спроектированном языке ассемблера
(формат YAML) и переводит её в промежуточное представление -- список
инструкций с полями команд из спецификации УВМ.

Язык реализации: Python 3, для разбора YAML используется
библиотека PyYAML.

## 2. Спецификация УВМ (вариант 22)

Команда УВМ занимает 10 байт. Биты нумеруются с нуля, от младшего
бита к старшему; байты в файле идут от младшего к старшему.

| Команда | Код (A) | Поля (биты) | Смысл |
|---|---|---|---|
| Загрузка константы | 17 | B: 6--29, C: 30--50 | память[B] = C |
| Чтение из памяти | 43 | B: 6--29, C: 30--53 | память[B] = память[C] |
| Запись в память | 21 | B: 6--29, C: 30--38, D: 39--62 | память[память[D] + C] = память[B] |
| Циклический сдвиг влево | 57 | B: 6--29, C: 30--53, D: 54--77 | память[C] = память[D] цикл.сдвиг влево на память[B] |

Этап 1 выполняет только перевод в промежуточное представление;
машинный код -- этап 2, интерпретатор -- этапы 3--4.

## 3. Язык ассемблера (формат YAML)

Программа -- YAML-список, каждый элемент -- одна команда: ключ --
имя команды, значение -- словарь её полей.

```yaml
- load:
    addr: 67       # B -- адрес, value -- константа (C)
    value: 619
- read:
    dst: 737       # B -- куда записать
    src: 274       # C -- откуда прочитать
- write:
    src: 662       # B -- откуда читаем значение
    offset: 337    # C -- смещение (9 бит: 0..511)
    base: 305      # D -- адрес ячейки с указателем
- rol:
    dst: 189       # C -- куда записать результат
    value: 940     # D -- первый операнд
    count: 766     # B -- второй операнд (величина сдвига)
```

Соответствие полей языка и спецификации: `addr`/`dst`/`src`/`count`
-- поле B, `value`/`src`/`offset`/`dst` -- поле C, `base`/`value`
-- поле D. Поля -- целые неотрицательные числа (можно в кавычках
и в шестнадцатеричном виде, например `0x2A`).

Ограничения по ширине полей: адреса -- 24 бита (0..16777215),
константа `load` -- 21 бит (0..2097151), смещение `write` --
9 бит (0..511).

## 4. Параметры запуска

```
python src/main.py <вход.yaml> <выход> [--test]
```

| Аргумент | Назначение |
|---|---|
| `вход` | путь к файлу с программой (YAML) |
| `выход` | файл, куда пишется промежуточное представление |
| `--test` | режим тестирования: результат печатается и на экран |

Формат вывода повторяет тесты спецификации: одна строка на команду,
`имя: A=код B=.. C=.. D=..`.

## 5. Обработка ошибок

Все ошибки выводятся понятным сообщением, код возврата 1:

- входной файл не найден, это папка или не текст UTF-8;
- ошибка синтаксиса YAML (с номером строки и столбца);
- программа не список, элемент не запись `имя: поля`;
- неизвестное имя команды (список доступных в сообщении);
- нет обязательного поля, лишнее поле;
- поле не целое число, отрицательное или вне диапазона;
- нельзя записать выходной файл.


## 7. Запуск и тесты

Требуется Python 3.8 или новее. Зависимость устанавливается
автоматически при первом запуске скрипта (либо вручную:
`python -m pip install PyYAML`).

| Действие | Windows | Linux |
|---|---|---|
| Диалоговый запуск | `run.bat` | `sh run.sh` |
| Тесты | `run.bat test` | `sh run.sh test` |
| Пример из спецификации | `run.bat demo` | `sh run.sh demo` |
| Запуск напрямую | `python src\main.py examples\demo.yaml out.txt --test` | `python3 src/main.py examples/demo.yaml out.txt --test` |

Скрипт `run.bat`/`run.sh` работает в цикле: команда `test` запускает
тесты, `demo` -- пример, `exit` -- выход; окно само не закрывается.

Ожидаемый вывод `run.bat demo` (промежуточное представление
совпадает с тестами спецификации):

```
Команд: 4. Промежуточное представление записано: temp\demo.txt
load: A=17 B=67 C=619
read: A=43 B=737 C=274
write: A=21 B=662 C=337 D=305
rol: A=57 B=766 C=189 D=940
```

## 8. Тестирование

Тесты покрывают: разбор всех четырёх команд УВМ со значениями полей
из спецификации, сборную программу из четырёх команд, пустую
программу, числа в кавычках и в шестнадцатеричном виде, формат
строки вывода, а также все перечисленные в разделе 5 ошибки.

```

$ sh run.sh test
...
Ran 33 tests in 0.013s

OK
```

## 9. Соответствие требованиям к репозиторию

- README.md, .gitignore, `src/`, `tests/`, `run.sh`/`run.bat` есть;
- бинарных файлов, архивов, `__pycache__` и настроек редакторов нет
  (`*.bin`, `*.csv`, `temp/` исключены `.gitignore`);
- строки кода Python не длиннее 79 символов, функции не длиннее
  40 строк, аргументов не больше 7, документация -- docstring,
  имена -- по PEP8, «магические» числа вынесены в именованные
  константы (`CMD_SIZE`, `ADDR_BITS`, `CONST_BITS`, `OFFSET_BITS`).
