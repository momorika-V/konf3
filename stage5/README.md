# Ассемблер и интерпретатор УВМ -- Этап 5. Тестовая задача

## 1. Общее описание

Учебная виртуальная машина (УВМ), вариант 22, финальный этап.
Разработаны ассемблер (язык на основе YAML, машинный код по 10 байт
на команду) и интерпретатор (объединенная память, команды load,
read, write, rol). На этом этапе ассемблер и интерпретатор применены
к тестовой задаче: поэлементный побитовый циклический сдвиг влево
над двумя векторами длины 5 с записью результата во второй вектор,
а также приведены три примера программ над различными данными.

Язык реализации: Python 3, для разбора YAML -- PyYAML.
Весь код -- в одном файле `src/main.py`.

## 2. Спецификация УВМ (вариант 22)

Команда -- 10 байт, биты нумеруются от младшего к старшему.

| Команда | Код (A) | Поля (биты) | Смысл |
|---|---|---|---|
| Загрузка константы | 17 | B: 6--29, C: 30--50 | память[B] = C |
| Чтение из памяти | 43 | B: 6--29, C: 30--53 | память[B] = память[C] |
| Запись в память | 21 | B: 6--29, C: 30--38, D: 39--62 | память[память[D] + C] = память[B] |
| Циклический сдвиг влево | 57 | B: 6--29, C: 30--53, D: 54--77 | память[C] = память[D] цикл.сдвиг влево на память[B] |

Ячейка памяти -- 21 бит (ширина поля константы); сдвиг выполняется
по модулю 21, старший бит уходит в младший.

## 4. Тестовая задача и примеры

| Команда скрипта | Программа | Что делает | Дамп |
|---|---|---|---|
| `demo` | `examples/task_vectors.yaml` | тестовая задача: rol над векторами длины 5, результат во втором векторе | адреса 155..179 |
| `ex1` | `examples/copy.yaml` | копирование массива из 5 ячеек (100..104) в 110..114 | адреса 95..119 |
| `ex2` | `examples/write_demo.yaml` | запись значений по указателю со смещением: память[80..82] = 11, 22, 33 | адреса 0..89 |
| `ex3` | `examples/rol_demo.yaml` | циклические сдвиги, включая переход старшего бита в младший | адреса 195..214 |

Ожидаемый результат `demo` (дамп `temp/task.csv`):

```
170,2          <- rol(1, 1)
171,1020       <- rol(255, 2)
172,8192       <- rol(1024, 3)
173,197520     <- rol(12345, 4)
174,2097135    <- rol(1048575, 5)
```

## 5. Параметры запуска

Режим выбирается по расширению входного файла:

```
python src/main.py <вход.yaml> <выход.bin> [--test]        ассемблер
python src/main.py <вход.bin> <дамп.csv> [начало конец] [--test]
```

- `--test` у ассемблера печатает машинный код, у интерпретатора --
  трассировку выполняемых команд (`адрес: команда и поля`).

## 6. Обработка ошибок

Все ошибки этапов 1--4: файлы, синтаксис YAML (строка и столбец),

## 8. Запуск и тесты

Требуется Python 3.8 или новее. Зависимость устанавливается
автоматически при первом запуске скрипта (либо вручную:
`python -m pip install PyYAML`).

| Действие | Windows | Linux |
|---|---|---|
| Диалоговый запуск | `run.bat` | `sh run.sh` |
| Тесты | `run.bat test` | `sh run.sh test` |
| Тестовая задача | `run.bat demo` | `sh run.sh demo` |
| Примеры 1--3 | `run.bat ex1` ... `ex3` | `sh run.sh ex1` ... `ex3` |

Скрипт работает в цикле: команда `test` запускает тесты, `demo`,
`ex1`, `ex2`, `ex3` -- примеры, `exit` -- выход; окно само
не закрывается.

## 9. Тестирование

Все конструкции языка и команды УВМ покрыты тестами: разбор всех
четырех команд со значениями из спецификации, машинный код --
точное совпадение со всеми тестовыми последовательностями
спецификации, декодирование, каждая команда интерпретатора,
циклический сдвиг (включая полный оборот и переход старшего бита),
тестовая задача и все три примера, ошибки файлов и данных.

```

$ sh run.sh test
...
Ran 66 tests in 0.036s

OK
```
